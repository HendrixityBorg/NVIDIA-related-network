# Agent 工作流与责任边界

`init-run` 会为每个研究运行生成 11 份机器可读 `agent_tasks/*.json`：通用来源发现、目标监管/IR、官方文章、产品树、生态网络、第三方新闻、实体解析、对手方反向监管复核、关系裁决、peer 研究和独立 QA。

Agent 可以自动发现数据源，而不是依赖 NVIDIA 固定 URL；但自动发现不等于任意抓取。每个 Agent 都必须遵守公开访问、robots、登录、付费墙、验证码、限流、许可和敏感数据边界。站点需要定制适配时，记录 `adapter_required`，不得把未覆盖页面标为 complete。

完成标准由可验证产物定义：枚举型任务要有 frontier 和每项终态，抽取型任务要保留 evidence locator，实体解析要有证券/母公司依据，关系裁决要说明方向、产品、状态、时间和评分，反向复核要覆盖最终图中的全部上市对手方，QA 要独立检查计数和引用。Agent 不得只返回摘要或“找到了若干条”。

人工研究负责人对范围、来源合法性、实体身份、事实/推断/未知、关系方向、评分和最终发布负责。AI 的任务是扩大可审计覆盖和发现异常，不是替代研究判断。
